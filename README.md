# Iron Nest: Heavy Turret Simulator Turret Optimization

Added keyboard support for the turret console, Allowing for custom animation speed and Unlock Elevation Slider during Reloading.

Adjust the settings in `BepInEx\config\com.kmyuhkyuk.IronNestTurretOptimization.cfg` then restart the game.

## How Install
Install BepInEx-6.0.0BE to the game.

Extract the archive to get folder then place folder into the game directory.
